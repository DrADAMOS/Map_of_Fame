# Historical data source policy

Map of Fame's learning database is educational content, so generated text must not be treated as authoritative merely because it came from a web page.

## Source hierarchy
1. Primary sources and authoritative institutional references for disputed/sensitive facts.
2. Scholarly reference works and reputable encyclopedias.
3. Wikidata statements with references for structured identifiers, dates and places.
4. Language-specific Wikipedia biographies as a secondary synthesis/discovery layer.

Wikidata's own sourcing guidance says statements should be verifiable and preferably backed by references. The cross-verified notable-people research also demonstrates the value of combining Wikidata with multiple Wikipedia editions while warning about conflicts and sparse records.

## Required editorial rule
A placeholder is never a fact. The build must fail if generic placeholder phrases remain in learning fields.
